# Shohagh Portfolio (Next.js)

Static portfolio for Md. Shahedur Rahman. Built with Next.js (static export) and deployed to GitHub Pages by GitHub Actions.

## Run locally
    npm install
    npm run dev

## Edit content
All text lives in `app/data.js` and `app/page.js`. Photo and resumes are in `public/`.

## Deploy
Push to the `main` branch. In the repository go to Settings -> Pages -> Source -> **GitHub Actions**.
